# V6.60 Notification Delivery Foundation

## Goal

Prepare notification delivery contracts without sending messages.

## Channels

- `in_app`: active/local
- `email`: planned/disabled
- `telegram`: planned/disabled
- `line`: planned/disabled

## Boundary

No secrets, tokens, environment variables, external delivery, push, email, Telegram, LINE, broker integration, trading, recommendations, or AI model calls.
