## Service Worker Safety Plan

Do not cache:

- `/admin`
- `/admin/*`
- `/api/admin/*`
- scheduler / cron endpoints
- unpublished draft APIs
- auth/session-sensitive endpoints
- service-role-backed admin writes

Safe candidates for future runtime caching:

- static assets
- icons and manifest
- public shell CSS/JS
- published Weekly Brief routes
- published Daily Brief responses after production Supabase verification
- About / Pro / FCN education pages

Market quote guidance:

- Do not long-term offline cache live market prices.
- If quote data is stale, UI must explicitly label it as stale, delayed, or unavailable.
- Avoid showing offline cached quotes as current market data.
