# IXAI v1.20 Account Foundation

v1.20 establishes the Public App account foundation while preserving Guest mode and the existing Daily Intelligence, FCN, market, and admin systems.

## Logo Verification

- Source of truth: `public/logo/ixuan-logo.png`
- Shared component: `components/brand/ixai-logo.tsx`
- Runtime path: `/logo/ixuan-logo.png`
- The About page, app shell, sidebar, footer, install card, and account surfaces should use the shared logo component instead of generated PWA icons or favicon assets.

## Account Routes

- `/login`: email/password login through Supabase Auth when env vars are configured.
- `/register`: email/password registration through Supabase Auth when env vars are configured.
- `/account`: identity status, Guest mode, sync readiness, future IXAI Pro handoff, and future notification preference explanation.

Guest users can continue using:

- Daily Brief
- Weekly Brief
- Market overview
- Watchlist on this device
- PWA install surfaces

## Environment Variables

Client-safe Supabase Auth:

- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`

Server-only keys such as `SUPABASE_SERVICE_ROLE_KEY` must not be used in login/register UI or client components.

## Database Preparation

Migration:

- `supabase/migrations/003_ixai_account_foundation.sql`

Tables prepared:

- `ixai_user_profiles`
- `ixai_user_preferences`

The migration is additive. It does not remove older preference columns such as `preferred_categories`, and it adds future booleans for:

- Watchlist sync readiness
- IXAI Pro handoff readiness
- Daily Brief notification preference
- Market risk notification preference
- FCN risk notification preference

## Watchlist Continuity

Current public copy should remain clear:

> 目前此裝置保存；登入後將逐步支援跨裝置同步。

Do not claim cross-device Watchlist sync is active until the runtime persistence and UX have been fully validated.

## IXAI Pro Connection

v1.20 does not merge Public App and Pro Dashboard auth.

The account page may describe:

- Public account today
- Future shared login/session
- Future Watchlist and AI memory sync
- Future Pro entitlement/payment state

It must not imply IXAI Pro access, payment, or account handoff is already active.

## PWA Cache Safety

The service worker should exclude auth-sensitive routes and APIs:

- `/login`
- `/register`
- `/account`
- `/auth`
- `/api/auth`
- `/api/session`
- `/api/supabase`
- `/api/user`

Admin, draft, scheduler, and service-role routes remain excluded.
