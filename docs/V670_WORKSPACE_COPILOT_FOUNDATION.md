# V6.70 Workspace Copilot Foundation

## Goal

Create a safe explain-only Copilot foundation for Workspace readback.

## Capabilities

- `explain_portfolio`
- `explain_risk`
- `explain_fcn`
- `explain_schedule`
- `explain_alerts`
- `explain_data_quality`

## Boundary

Copilot is rule-based only. It does not call AI models and does not provide buy, sell, hold, target price, order routing, broker action, return promise, or investment recommendation logic.
